Greedy Optimality Analysis
✓ Optimal cases
Single isolated intersection
Max-flow-first is provably optimal — no downstream interactions to consider.
Emergency vehicle preemption
Single-objective problem: highest-priority vehicle wins. Priority queue gives optimal result.
Independent road segments
Each segment is separable — local greedy choice equals global optimum.
✗ Suboptimal cases (Cairo)
Downtown grid (nodes 3,6,9,10,F2)
Cycle spillback: greedy at node 3 may block node 9. Coordinated SCOOT plans beat greedy by ~15%.
Event demand surge at Cairo Stadium
Greedy reacts only to current flow — cannot anticipate post-match surge. ML timing wins by ~20%.
Multi-modal conflict at Ramses (F2)
Metro + bus + car phases interact. Greedy ignores transit priority; weighted approach needed.
